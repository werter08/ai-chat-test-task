# CLAUDE.md — rules for the agent

Project: **AIChat**, a ChatGPT-style iOS 18+ chat app (plus a macOS target). Task description: `docs/TASK.md`. Plan: `docs/PLAN.md`.

## Stack
- Swift 5 mode, SwiftUI, SwiftData (persistence), Observation (`@Observable`), `URLSession` + SSE for streaming.
- Project generated by **XcodeGen** from `project.yml`. Never hand-edit or commit the `.xcodeproj`.
- Dependencies: Swift Package Manager only. Currently none are needed — keep it that way unless justified.
- Deployment targets: iOS 18.0, macOS 15.0. Do not use APIs newer than that without `if #available` guards.
- AI backend: OpenRouter (`/api/v1/chat/completions`, `stream: true`), model id from `.env` (default `baidu/ernie-5.5-flash-preview:free`).

## Layout
- `Shared/` — all app code, compiled into both the iOS and macOS targets. `#if os(...)` only when unavoidable.
  - `Models/` SwiftData models · `Networking/` client, SSE parser, errors · `Security/` key vault · `Features/` views + `ChatEngine`.
- `Mac/` — macOS entitlements. `Tests/` — unit tests. `scripts/` — build helpers.

## Rules
1. **Secrets:** never print, log, commit or paste the API key. `.env` is gitignored. Only the obfuscated `Shared/Security/Secrets.generated.swift` is committed. Use `<API_KEY>` in docs.
2. Keep layers separate: views → `ChatEngine` (state + orchestration) → `ChatStreaming` protocol (`OpenRouterClient`) → network. Views never touch URLSession.
3. Every network failure maps to a `ChatAPIError` with a user-facing message; the UI must offer **Retry** for it.
4. Streaming must be cancellable (Stop button → task cancel); partial replies are kept.
5. Commit in small steps with clear messages. Never commit `.env`, `build/`, or `*.xcodeproj`.
6. Verify before claiming done: `./Build.command` must succeed, and `xcodebuild test` must pass.

## Commands
- Build + run on simulator: double-click `Build.command` (or `./Build.command`).
- Tests: `xcodegen generate && xcodebuild test -project AIChat.xcodeproj -scheme AIChat -destination 'platform=iOS Simulator,name=iPhone 17' CODE_SIGNING_ALLOWED=NO`
